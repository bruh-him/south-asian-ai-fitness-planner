# Add a South Asian food safely

When adding a food/dish to the ontology:

1. Add the canonical name.
2. Add common English + regional/transliterated aliases.
3. Add region/subregion/cuisine.
4. Classify the food type.
5. Record typical ingredient families.
6. Record typical cooking method.
7. Choose a nutrition-source strategy.
8. Do **not** invent nutrient values just to complete the row.
9. If nutrition values are needed, use an authoritative composition source or a transparent recipe calculation.
