# Contributing

Contributions should improve correctness, provenance, usability or coverage without weakening source attribution.

## Rules

- Do not fabricate nutrient values.
- Keep the ontology separate from nutrient composition.
- Prefer authoritative food-composition sources.
- Preserve upstream attribution.
- Document material changes to Claude prompts.
- Add tests for new normalization behavior.

## Commit style

Use conventional prefixes where practical:

- `feat:`
- `fix:`
- `docs:`
- `data:`
- `refactor:`
- `test:`

## Attribution

Any copied third-party code/data must retain the applicable copyright/license notices.
